# Support policy

The current major release supports Python 3.10–3.13 on Linux, macOS, and Windows. Security reports follow SECURITY.md; usage questions and reproducible bug reports belong in the public issue tracker. CTXORA Free provides the unlimited local engine with best-effort community support and no SLA. CTXORA Pro is waitlist-only and covers planned managed automation, private workflows and team context; its billing, entitlement and hosted collaboration systems are not implemented in this repository and are never required to install or run CTXORA Engine locally.
